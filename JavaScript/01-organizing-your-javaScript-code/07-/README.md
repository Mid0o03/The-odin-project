# 07 - LocalStorage Practice

A simple exercise demonstrating how to use the Web Storage API (localStorage) in JavaScript.

## Concepts Covered
- **JSON Serialization**: Converting Objects to strings with `JSON.stringify()`.
- **Data Persistence**: Saving data to `localStorage`.
- **Data Retrieval**: converting strings back to Objects with `JSON.parse()`.

## Usage
Open `script.js` to see the logic. Run it in a browser console to see the output.
