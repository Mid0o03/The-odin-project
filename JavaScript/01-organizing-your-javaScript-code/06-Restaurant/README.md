# 06 - Restaurant Page

A dynamically generated restaurant homepage using JavaScript, Webpack, and CSS Grid.

## Features
- **Dynamic Content**: The entire page content is generated via JavaScript.
- **Tabbed Navigation**: Switch between Home, Menu, and Contact pages without reloading.
- **Webpack Bundling**: Uses Webpack to bundle assets and modules.
- **Premium Design**: Modern, responsive UI with a "Modern Bistro" aesthetic.

## Tech Stack
- HTML5
- CSS3 (Grid, Flexbox)
- JavaScript (ES6 Modules)
- Webpack

## Installation

```bash
npm install
npm run build
```

Open `dist/index.html` to view the site.
