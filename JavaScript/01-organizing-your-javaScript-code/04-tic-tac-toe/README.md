# Tic-Tac-Toe

A modern, browser-based Tic-Tac-Toe game built with vanilla JavaScript, HTML, and CSS. This project focuses on implementing clean, modular code using JavaScript's **Module Pattern** and **Factory Functions**.

## Features

- **Interactive UI**: Clean and responsive game board.
- **Game Logic**: Full game state management, including win detection and tie handling.
- **Module Pattern**: Used to encapsulate game board logic and display controls, preventing global namespace pollution.
- **Factory Functions**: Employed to create player objects dynamically.

## How to Play

1. Open `index.html` in your web browser.
2. Player 1 starts as "X" and Player 2 as "O".
3. Click on any empty cell to place your marker.
4. The first player to get three in a row (horizontally, vertically, or diagonally) wins!
5. Press the "Restart" button to start a new game.

## Learning Objectives

- Practice DOM manipulation and event listeners.
- Implement the Module Pattern for logic encapsulation.
- Use Factory Functions to create objects with private state.
- Manage complex game states without using global variables.
