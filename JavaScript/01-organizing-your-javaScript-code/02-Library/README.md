# Library Project

A simple web application to manage a personal library of books. This project is part of The Odin Project's JavaScript course.

## Features

*   Add new books with title, author, and number of pages.
*   Toggle read status for each book.
*   Remove books from the library.
*   Persistent storage (simulated via in-memory array, or potentially LocalStorage in future updates).

## Key Concepts Practiced

*   Object Constructors
*   Prototypes and inheritance
*   DOM Manipulation
*   Event Handling
*   Array methods (`push`, `splice`, etc.)

## How to use

Simply open `index.html` in your browser.
