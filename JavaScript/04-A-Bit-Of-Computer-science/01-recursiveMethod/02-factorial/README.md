# Factorial Function

This exercise contains a recursive function to calculate the factorial of a given number. The factorial of a non-negative integer `n` is the product of all positive integers less than or equal to `n`.

## Features
- Input validation to ensure the argument is a positive integer.
- Recursive approach to compute the factorial.
- Base case correctly handles `0! = 1`.

## Example
```javascript
factorial(5); // returns 120
```
