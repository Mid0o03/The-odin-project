# Fibonacci Number Generator

This exercise demonstrates a function that returns the nth number in the Fibonacci sequence. The function takes a single argument, `count`, which represents the position in the sequence, and returns the corresponding Fibonacci number.

## Features
- Input validation to ensure the argument is a non-negative integer.
- Iterative approach (using a `for` loop) to calculate the Fibonacci number efficiently without the overhead of recursion.

## Example
```javascript
fibonacci(4); // returns 3
fibonacci(0); // returns 0
```
