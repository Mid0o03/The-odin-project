# JavaScript Testing Basics - The Odin Project

Ce projet contient des exercices fondamentaux sur les tests unitaires en JavaScript en utilisant **Jest**. Il fait partie du module "Testing JavaScript" de **The Odin Project**.

## 🧪 Exercices inclus

Le fichier `index.js` contient les implémentations suivantes :

1.  **capitalize(string)** : Met la première lettre d'une chaîne en majuscule.
2.  **reverseString(string)** : Inverse une chaîne de caractères.
3.  **calculator** : Un objet avec les méthodes `add`, `subtract`, `multiply`, et `divide`.
4.  **caesarCipher(string, shift)** : Un algorithme de décalage de César qui gère la rotation de 'z' à 'a', la casse et la ponctuation.
5.  **analyzeArray(array)** : Analyse un tableau de nombres pour retourner sa moyenne, son min, son max et sa longueur.

## 🛠️ Configuration

- **Jest** : Framework de test.
- **Babel** : Utilisé pour supporter la syntaxe ES6 (`import`/`export`) dans les tests Jest.

## 🚀 Lancement des tests

1. Installez les dépendances :
   ```bash
   npm install
   ```
2. Lancez les tests Jest :
   ```bash
   npm test
   ```
