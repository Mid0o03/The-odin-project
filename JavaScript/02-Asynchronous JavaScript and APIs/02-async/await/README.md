# Async/Await Web API Example

This directory contains an example project applying the `async` and `await` keywords in JavaScript to cleanly handle asynchronous operations like fetching data from a RESTful API.

## Features
- Fetches a random GIF from the Giphy API using `fetch`.
- Employs `async`/`await` for readable, synchronous-looking asynchronous code.
- Implements `try`/`catch` blocks for robust error handling.
- Updates an `img` DOM element with the retrieved GIF sequence.
- Attaches an event listener to fetch and display a new GIF upon clicking a button.
