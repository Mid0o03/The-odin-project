# Weather App - The Odin Project

Une application météo moderne construite avec JavaScript, Webpack et l'API Visual Crossing. Ce projet fait partie du cursus JavaScript de **The Odin Project**.

## ✨ Fonctionnalités

- **Recherche de ville** : Obtenez la météo actuelle pour n'importe quelle ville dans le monde.
- **Design Premium** : Interface moderne avec effets de **Glassmorphism** et mode sombre.
- **Interface réactive** : Feedback en temps réel avec indicateur de chargement (spinner).
- **Gestion des erreurs** : Messages clairs en cas de ville non trouvée ou d'erreur réseau.
- **API Asynchrone** : Utilisation de `async/await` pour des appels API fluides.

## 🛠️ Technologies utilisées

- **JavaScript (ES6+)**
- **Webpack 5** (Module bundling)
- **CSS3** (Variables, Flexbox, Animations)
- **API Visual Crossing** (Données météo)

## 🚀 Installation & Lancement

1. Clonez le dépôt :
   ```bash
   git clone [url-du-repo]
   ```
2. Installez les dépendances :
   ```bash
   npm install
   ```
3. Lancez le serveur de développement :
   ```bash
   npm start
   ```
4. Pour construire le projet pour la production :
   ```bash
   npm run build
   ```
