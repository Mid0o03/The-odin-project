# Asynchronous JavaScript - Giphy API

## Project Overview
This project is a simple implementation of asynchronous JavaScript using the Giphy API.
It demonstrates how to fetch data from an external API, handle promises, and update the DOM dynamically.

## Features
-   **Fetch API**: Retrieves a random GIF related to "cats".
-   **Error Handling**: Catches errors (e.g., invalid API key, network issues) and alerts the user.
-   **Dynamic DOM Updates**: Updates the image source with the retrieved GIF URL.

## Setup
1.  Clone the repository.
2.  Open `index.html` in your browser.
3.  Click the "Load" button or refresh to see a new GIF.
