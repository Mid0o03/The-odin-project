# Form Advance

This project is a solution to the "Form Advance" assignment from The Odin Project. It demonstrates advanced form controls, validation, and styling using HTML and CSS.

## Features

-   **Advanced Form Controls**: Uses `input` types like `date`, `range`, and `datalist` for location selection.
-   **Validation**: Client-side validation with `minlength`, `required`, and custom styling for invalid inputs (red border and background).
-   **Responsive Design**: Centered form with a modern look using a custom fieldset and buttons.

## Technologies Used

-   HTML5
-   CSS3

## Usage

Open `index.html` in your web browser to view the form.
