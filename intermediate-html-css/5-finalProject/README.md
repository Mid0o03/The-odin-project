# Admin Dashboard

This is the final project for the Intermediate HTML and CSS course from The Odin Project. It recreates a responsive admin dashboard layout.

## Features

-   **Complex Grid Layout**: Uses CSS Grid for the main structure (Sidebar + Content).
-   **Flexbox Components**: Utilizes Flexbox for alignment within headers, cards, and navigation.
-   **Responsive Design**: Adapts grid columns for cards using `repeat(auto-fit, minmax(...))`.
-   **Styled Components**: Custom buttons, input fields, and card designs with hover effects and shadows.

## Structure

-   `index.html`: The HTML structure including sidebar, header, and main content area.
-   `style.css`: The CSS styling using CSS variables for colors and consistent spacing.
